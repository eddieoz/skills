# Writing Assistant

A pack of five composable writing skills. Install individual skills from the `skills/` (or `writing-assistant/`) subdirectory, or use this meta-skill as an index.

## Included skills

- **critique-content** — hostile red-team analysis
- **document-reference-validator** — citation & reference verification
- **persuasive-analysis** — rhetorical effectiveness (logos/ethos/pathos)
- **proof-read** — mechanical + editorial polish and humanization
- **text-assessment** — 5-dimension systematic evaluation
